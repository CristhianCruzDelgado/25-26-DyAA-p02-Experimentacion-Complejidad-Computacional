## Implementation

A **Random Access Machine (RAM)** is a theoretical model used to analyze the computational complexity of different algorithms.

This is because it has three fundamental characteristics
1. It has no concurrency.
2. Its instructions run in constant time.
3. It allows measuring the number of executed instructions.

> The complexity of a program in the RAM machine is equivalent to the number of instructions executed by it.
